      Torneo de eSports
Esta es la aplicación web que desarrollé para la gestión e inscripción de equipos en un torneo local de videojuegos, cumpliendo con todos los requisitos académicos solicitados.

   Tecnologías que utilicé
- Node.js y Express: Para levantar el servidor web y configurar las rutas principales.

- Handlebars (hbs): Como motor de plantillas para renderizar las vistas de forma dinámica.

- MongoDB y Mongoose: Para gestionar la persistencia de los datos en la base de datos de manera estructurada.

    Funcionalidades principales
- Landing Page: Una página de inicio de presentación para el torneo.

- Formulario de Inscripción (POST): Permite registrar equipos ingresando el nombre del equipo, nombre del capitán, juego seleccionado, correo electrónico de contacto y la cantidad de jugadores suplentes.

- Listado de Inscriptos: Una vista en formato de tabla que consulta en tiempo real la base de datos para mostrar todos los equipos que se van anotando.
